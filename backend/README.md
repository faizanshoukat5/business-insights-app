# Business Insights API (backend)

Express + Mongoose REST API for the Business Insights App. Full documentation — API reference, live URL, demo credentials, Postman guide — lives in the [root README](../README.md).

Quick start:

1. `npm install`
2. Copy `.env.example` to `.env` and set `MONGODB_URI` and `JWT_SECRET`
3. `npm run seed` — seeds the demo user, business, insights, and reviews
4. `npm run dev` — starts the API on http://localhost:5000
5. `npm test` — runs the Jest test suite
